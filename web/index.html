From Web Fixture to Analytics Warehouse

An event-driven football ETL pipeline. GitHub Actions schedules crawls, FastAPI acts as an authenticated ingestion gateway, Apache Kafka buffers raw and cleansed event streams, Python microservices transform fixtures, and PostgreSQL stores analytical models.

Sample event: Arsenal vs Chelsea Premier League

🔄 Self-Healing Closed-Loop Intelligence

The scheduler never directly connects to PostgreSQL. Before crawling, it calls GET /crawl-state on FastAPI to ask which leagues are due. When fixtures finish, the Loader recalculates next_recrawl_at = max(kickoff) + 3h, ensuring zero redundant crawls and zero missed match results.
