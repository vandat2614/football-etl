One match, from the web to the database

A pipeline that crawls football fixtures, streams them through Kafka, cleans them and stores them in PostgreSQL. Press the button to follow a single match through every stage, or click any stage to read what it does.

Bayern München vs Wolfsburg, 2010-2011

The scheduler does not touch the database. Before crawling it asks the API which leagues are due, and the load step records when each league must be crawled again.
