From Web Fixture to Analytics Warehouse

An event-driven football ETL pipeline. GitHub Actions schedules crawls, FastAPI acts as an authenticated ingestion gateway, Apache Kafka buffers raw and cleansed event streams, Python microservices transform fixtures, and PostgreSQL stores analytical models.

The Closed-Loop Feedback Cycle

The scheduler never directly touches PostgreSQL. Before crawling, it queries GET /crawl-state from the API to check which tournaments are due. When fixtures finish, the Loader recalculates next_recrawl_at = max(kickoff) + 3h, ensuring zero redundant requests and zero missed match results.
